
# Componente
Partes comunes
- Las partes comunes que se usan en los ajustes de cada lugar se extraen y se tratan aparte.
- Los componentes que se usan en cualquiera de esos lugares son comunes, pero según el lugar hay campos del componente que no se usan.

|Componente|Descripción|
|-|-|
|[_information_](es/editor/information)|La configuración de la información básica del elemento (ID, nombre, explicación, icono y color)|
|[_requirement_](es/editor/requirement)|La configuración de las condiciones necesarias para usar o mostrar un elemento|
|[_acquisition_](es/editor/acquisition)|La configuración de la obtención de artículos y de niveles de categoría|
|[_combat_](es/editor/combat)|La configuración de las correcciones de combate en las acciones del tipo stamina|
|[_property_](es/editor/property)|La configuración de los efectos que tiene un artículo|
