
# Dunia
Pengaturan dan struktur data seluruh dunia permainan
- Ini data definisi permainan yang dimuat di player untuk dimainkan.
- Lewat pengaturannya, kamu bisa membuat game idle sesuai keinginanmu.
- Dunia memuat pengaturan dasar, enam tipe berupa kategori, aksi, item, skill, grup, dan preset, serta acara.
