
# Pengaturan dasar
Butir pengaturan dasar untuk dunia secara keseluruhan
- Mengatur nama, penjelasan, latar belakang, mata uang, kapasitas, level maksimum kategori, laju pertumbuhan pengalaman, parameter tempur standar, dan sebagainya dari dunia.
- Pengaturan ini berpengaruh pada seluruh dunia.
