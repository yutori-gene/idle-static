
# Compétence
Lorsqu'elle se déclenche en combat, elle ajuste les valeurs de combat pour ce tour uniquement
- Une compétence est un élément qui, lorsqu'il se déclenche en combat, ajuste les valeurs de combat pour ce tour uniquement
- Le déclenchement est tiré au sort à chaque tour, au maximum un par tour pour votre camp et pour l'adversaire. Si une autre compétence sort d'abord, il ne survient pas aussi souvent que la probabilité affichée
- Seule la récupération n'agit pas pendant ce tour : elle est appliquée d'un bloc dans la récupération qui suit l'issue du combat
___

## Liste des compétences
La liste des compétences que possède cet élément
- Répertorie les compétences que possèdent les objets de chaque catégorie
- Le pourcentage est la probabilité de déclenchement
- Les compétences du côté de l'action se consultent dans la colonne de l'action
