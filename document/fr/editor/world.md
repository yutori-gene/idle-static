
# Monde
Les réglages et la structure de données de tout le monde du jeu
- Ce sont les données de définition du jeu, chargées dans le lecteur pour y jouer.
- Grâce aux réglages, vous pouvez créer le jeu idle que vous avez en tête.
- Un monde contient les réglages de base, les six types que sont catégorie, action, objet, compétence, groupe et préréglage, ainsi que les événements.
