
# Evento
O conjunto de eventos do mundo, reunindo as tarefas, os eventos de mudança e os eventos fixos
- Os eventos de um mundo são compostos por três tipos: tarefas (tasks), eventos de mudança (changed) e eventos fixos (unique).
- Uma tarefa é uma missão que é alcançada ao se cumprirem os requisitos.
- Um evento de mudança é um evento de processamento interno, que não aparece na tela e é ativado repetidamente tendo como gatilho o aumento de uma quantidade.
- Um evento fixo é uma vaga preparada uma por momento, que não dá para acrescentar nem excluir.

|Tipo|Descrição|
|-|-|
|[_task_](pt/editor/task)|Uma missão que é cumprida quando as condições são atendidas|
|[_changed_](pt/editor/changed)|Um evento de processamento interno que dispara quando a quantidade de uma categoria, uma ação ou um item aumenta de uma vez na quantidade das condições ou mais|
|[_unique_](pt/editor/unique)|As mensagens e recompensas que são ativadas em momentos determinados|
