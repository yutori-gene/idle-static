
# Mundo
As configurações e a estrutura de dados de todo o mundo do jogo
- São os dados de definição do jogo, carregados no reprodutor para jogar.
- Com as configurações você pode criar o jogo idle que tiver em mente.
- Um mundo contém as configurações básicas, os seis tipos de categoria, ação, item, habilidade, grupo e predefinição, e ainda os eventos.
