
# Habilidade
Ao ser ativada durante o combate, ajusta os valores de combate apenas naquele turno
- Uma habilidade é um elemento que, ao ser ativado durante o combate, ajusta os valores de combate apenas naquele turno
- A ativação é sorteada a cada turno, no máximo uma por turno para o seu lado e para o adversário. Se outra habilidade for sorteada antes, ela não aparece tanto quanto a probabilidade exibida
- Só a recuperação não tem efeito naquele turno: ela é aplicada de uma vez na recuperação após o combate ser decidido
