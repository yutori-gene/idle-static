
# 방치형 게임 개발 플랫폼
월드라는 정의 데이터로 방치형 게임을 만들어 즐기기 위한 플랫폼
- 게임의 내용은 '월드'라고 부르는 정의 데이터에 정리되어 있습니다. 프로그램을 쓰지 않아도 에디터의 입력만으로 게임 하나를 조립할 수 있습니다.
- 만든 월드는 플레이어로 불러와 즐깁니다. 단독으로 동작하는 형태로 내보내면 그대로 배포할 수도 있습니다.
- 이 문서는 에디터와 플레이어의 2부 구성입니다. 월드를 만드는 쪽의 설정 항목은 에디터를, 즐기는 쪽의 화면은 플레이어를 참조하세요.
___

## 특징
플랫폼의 주요 기능과 특징
- 방치형 게임에 필요한 요소(카테고리·액션·아이템·스킬·그룹·프리셋)와 이벤트가 처음부터 준비되어 있어, 조합만으로 게임의 형태가 정해집니다.
- 화면을 닫고 있는 동안의 시간도 오프라인 진행으로 소화되므로, 방치한 만큼 진행됩니다.
- 10개 언어에 대응합니다. 화면의 공통 문구는 항상 동봉되고, 월드 자체의 문구도 언어별로 준비할 수 있습니다.
- 진행 상황은 브라우저에 월드별로 저장되며, 파일로 내보내 가지고 다닐 수 있습니다.
