
# 월드
게임 전체의 확인과 설정
- 최상단 칼럼의 월드 제목에서 엽니다.
- 디버그의 칼럼은 디버그 모드로 시작했을 때만 나타납니다.
___

## 개요
이 월드와, 그것을 실행하고 있는 콘솔의 개요를 표시
- 제작자·버전·예상 플레이 시간 등 월드의 기본 정보와, 기본 언어·최대 오프라인 시간·카테고리 레벨 상한·필요 경험치 증가 정도 같은 월드 전체에 공통되는 설정을 확인 가능
- 콘솔은 월드를 불러와 구동하는 실행 환경. 월드와는 별도로 버전과 갱신일을 가짐
___

## 통계
플레이를 통해 기록된 합계를 표시
- 플레이 시간과 획득 코인의 누계, 그리고 지금 보유 칸과 예약 칸(대기열)을 얼마나 가질 수 있는지 확인 가능
- 카테고리·액션·아이템·이벤트의 개방 수는 아직 찾지 못한 것까지 포함한 월드 전체의 수가 분모
- 코인이나 용량·대기열, 내역에 늘어선 카테고리는 탭하면 해당 화면을 열 수 있음
___

## 설정
이 게임의 설정 변경과 세이브 데이터의 관리를 수행
- 조작 방법·화면 표시·동작 부하를 바꿀 수 있음. 설정은 진행 데이터의 일부로 저장되어 내보낸 데이터에도 이어짐
- 진행 데이터는 이 기기에 월드별로 저장됨. 내보낸 파일을 불러올 수 있는 것은 같은 월드의 같은 버전뿐
___

## 디버그
월드를 테스트하기 위한 도구를 제공
- 디버그 모드로 실행했을 때만 표시됨. 일반 플레이에서는 나타나지 않음
- 가속 설정은 진행 데이터에 저장되지만, 효과가 있는 것은 디버그 모드일 때뿐
