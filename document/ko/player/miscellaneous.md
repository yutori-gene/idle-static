
# 보충 사항
특정 타입에 속하지 않는 칼럼
- 이벤트와 그룹의 칼럼은 어느 계층에서든 오른쪽으로 열립니다.
- 언어의 칼럼은 설정의 칼럼과 환영 이벤트의 칼럼에서 엽니다.
___

## [_이벤트_](ko/player/event)
___

## 그룹
카테고리·액션·아이템을 가로질러 묶는 분류
- 그룹은 카테고리·액션·아이템을 가로질러 묶는 분류
- 장비할 수 있는 아이템은 그룹당 하나뿐
- 오른쪽 값은 카테고리는 레벨, 액션은 필요 레벨, 아이템은 보유 수
___

## 언어
표시에 사용하는 언어를 변경
- 바뀌는 것은 화면의 언어
- 번역이 없는 문장은 기본 언어 그대로 표시됨
