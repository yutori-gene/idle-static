
# 조건
요소의 이용이나 표시에 필요한 조건 설정
- 카테고리, 액션, 아이템, 이벤트의 각 요소에 설정하는 조건입니다.
- 설정한 조건을 모두 충족하지 않으면 표에 제시한 조작을 할 수 없습니다.
- 요소의 개방 설정(unlocked)에 따라서는 조건을 충족할 때까지 요소 자체가 화면에 표시되지 않습니다.

|설정 위치|조건을 충족하지 않으면 할 수 없는 것|
|-|-|
|카테고리|카테고리 내 모든 액션의 실행과 아이템의 조작|
|액션|액션의 실행|
|아이템|아이템의 조작(장비 등)|
|이벤트|과제의 달성, 변화 이벤트와 고정 이벤트의 발동|
- [_type_](ko/editor/type)
___

## 타입
조건으로 참조할 요소의 종류

|타입|참조되는 값|
|-|-|
|카테고리|카테고리의 레벨|
|액션|액션의 실행 횟수|
|아이템|아이템의 소지 수|
___

## 요소의 ID
조건으로 참조할 요소의 ID
- 조건으로 참조할 카테고리, 액션, 아이템의 ID를 설정합니다.
- 이벤트에서 그룹 집계(requiringGroup)를 활성화한 경우에는 개별 요소가 아니라 그룹의 ID로 취급됩니다.
___

## 값
조건에 필요한 수치
- 지정한 값 이상인 경우에 조건을 충족합니다.
- 0 이상의 정수로 설정합니다. 기본값은 `1`입니다.
___

## 소비 확률[0-1]
아이템이 소비될 확률(0~1, 타입이 아이템인 경우에만 유효)
- 조건을 충족하여 액션이 실행되었을 때 아이템을 소비할 확률입니다.
- `1`이면 반드시 소비, `0.5`면 50% 확률로 소비, `0`이면 소비하지 않습니다.
- 기본값은 `1`(반드시 소비)입니다. 다만 이벤트(과제·변화 이벤트·고정 이벤트)의 조건에서는 달성해도 보유분이 줄지 않도록 기본값이 `0`(소비하지 않음)으로 되어 있습니다.
- `0`으로 한 경우에는 재고가 줄지 않으므로, 소지 수가 조건의 값에 도달해 있으면 몇 번이든 액션을 실행할 수 있습니다. 장비하고 있다는 것만을 조건으로 삼고 싶을 때 사용합니다.
- 타입이 아이템 이외인 경우에는 무효입니다.
___

## 장비
아이템이 장비 상태인 것을 조건으로 삼을지 여부(타입이 아이템인 경우에만 유효)
- 활성화하면 아이템을 소지하고 있는 것뿐 아니라 장비하고 있는 것이 조건으로 필요해집니다.
- 장비하고 있는지 여부는 그 아이템이 속한 카테고리의 장비로 판정됩니다.
- 타입이 아이템 이외인 경우에는 무효입니다.
