
# 개발
월드 개발 시의 메모와 오류 관리
- 월드를 개발할 때 사용합니다.
- 이 월드의 개발이나 테스트에 관한 것이며, 플레이 내용에는 영향이 없습니다.
- 개발에 관한 내용을 플레이어가 보는 일은 없습니다.
___

## 버전
에디터의 빌드 버전 번호
- 새 월드를 만든 시점의 에디터 버전 번호가 자동으로 기록됩니다.
- 기존 월드를 읽어 들여 편집해도 갱신되지 않습니다.
- 개발자는 이 내용을 변경할 수 없습니다.
___

## 메모
개발자용 메모 기록
- 개발자가 자유롭게 메모로 기재할 수 있습니다.
- 게임 공개와는 관련이 없습니다.
___

## 오류
검증 결과의 오류 기록
- 월드를 검증한 결과가 여기에 자동으로 저장됩니다.
- 예를 들어 입력할 수 없는 문자 종류가 있다거나 상한을 넘은 수치를 입력했다거나 하는 것을 오류로 표시합니다.
- 오류가 하나도 없었던 경우에는 대신 성공했음을 알리는 메시지가 한 줄만 저장됩니다.
- 개발자는 이 내용을 변경할 수 없습니다.
- 오류가 남아 있는 동안에는 월드를 공개할 수 없습니다. 공개 조작을 하면 먼저 검증이 실행되고, 오류가 있으면 거기서 중단됩니다.
___

## 타임스탬프
작성·저장·공개의 기록
- 월드의 작성, 저장, 공개 시각이 자동으로 기록됩니다.
- 개발자는 이 내용을 변경할 수 없습니다.
___

### 작성 일시
월드의 최초 작성 시각
- 월드가 처음 작성된 일시입니다.
___

### 저장 일시
마지막 저장 실행 시각
- 월드가 마지막으로 저장된 일시입니다.
___

### 공개 일시
마지막 공개 실행 시각
- 월드가 마지막으로 공개된 일시입니다.
___

## 자동 저장
자동 저장 기능의 활성화/비활성화
- 편집 내용을 브라우저에 자동으로 저장할지 여부를 나타냅니다.
- 이 항목을 직접 고쳐 쓸 수는 없습니다. 에디터 메뉴에 있는 자동 저장 전환으로 변경합니다.
