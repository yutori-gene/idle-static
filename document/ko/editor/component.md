
# 컴포넌트
공통 부품
- 각 부분의 설정에서 쓰이는 공통 부품은 따로 뽑아내어 다룹니다.
- 어느 부분에서 쓰이든 컴포넌트는 공통이지만, 부분에 따라서는 컴포넌트 중 쓰이지 않는 항목도 있습니다.

|컴포넌트|설명|
|-|-|
|[_information_](ko/editor/information)|요소의 기본 정보(ID, 이름, 설명문, 아이콘, 색)의 설정|
|[_requirement_](ko/editor/requirement)|요소의 이용이나 표시에 필요한 조건 설정|
|[_acquisition_](ko/editor/acquisition)|아이템과 카테고리 레벨의 취득 설정|
|[_combat_](ko/editor/combat)|stamina 타입의 액션에서의 전투 보정값 설정|
|[_property_](ko/editor/property)|아이템이 가지는 효과의 설정|
