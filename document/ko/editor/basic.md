
# 기본 설정
월드 전반의 기본적인 설정 항목
- 월드의 이름, 설명, 배경, 통화, 용량, 카테고리의 최대 레벨, 경험치의 상승률, 표준 전투 파라미터 등을 설정합니다.
- 이들 설정은 월드 전체에 영향을 줍니다.
