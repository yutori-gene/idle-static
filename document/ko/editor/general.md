
# 일반
언어, 레벨 설정 등 기본적인 게임 설정
___

## 언어
월드를 제작하는 언어
- 월드의 이름이나 설명을 어느 언어로 쓰고 있는지를 설정합니다. 번역을 준비할 때 바탕이 되는 언어입니다.
- 플레이어가 게임을 시작했을 때 가장 먼저 표시되는 언어이기도 합니다.
- 번역(translations)이 비활성일 경우, 플레이어는 이 언어에서 전환할 수 없습니다.
- 월드 에디터 자체의 표시 언어와는 별개의 설정입니다. 에디터의 표시 언어는 에디터를 열 때 선택합니다.
- [_translation_](ko/editor/translation)
___

## 번역
다국어 대응 번역을 준비할지 여부
- 활성일 경우, 플레이어가 원하는 언어로 전환해서 즐길 수 있습니다.
- 비활성일 경우, 언어(language)에서 선택한 언어로 고정되며 전환 조작 자체를 할 수 없습니다.
- 활성으로 할 경우, 각 언어의 번역 데이터를 준비해야 합니다. 공개 패키지에는 번역 데이터가 함께 담깁니다.
- 전환의 대상이 되는 것은 월드에서 정의한 이름과 설명입니다. 화면의 공통 문구(프리셋) 번역은 이 설정과 관계없이 항상 함께 담깁니다.
- [_translation_](ko/editor/translation)
- [_preset_](ko/editor/preset)

## 최대 오프라인 시간[시간]
오프라인 진행의 시간 제한
- 오프라인일 때의 진행을 최대 몇 시간으로 할지 설정합니다.
- 예를 들어 ６시간으로 한 경우에는 ６시간까지의 오프라인 복귀 처리가 이루어지지만, 그보다 오래 시간을 두고 오프라인에서 복귀해도 오프라인 시간은 ６시간으로 취급됩니다.
- ０시간으로 한 경우에는 오프라인 복귀 시의 처리가 전혀 이루어지지 않습니다.
- 최댓값은 24시간입니다.
- [_category_](ko/editor/category)
___

## 카테고리의 최대 레벨
각 카테고리의 레벨 상한
- 각 카테고리의 레벨 상한을 설정합니다. 기본값은 `100`입니다.
- 경험치를 얻어도 레벨은 이 값에서 멈추고, 초과한 만큼은 버려집니다. 보상으로 레벨을 직접 더한 경우에도 같습니다.
- 세이브 데이터의 레벨이 상한을 넘어 있던 경우에는 읽어 들일 때 상한까지 잘립니다.
- 레벨 바와 통계의 진척률은 이 값을 분모로 삼아 표시됩니다.
- 수치(numeric)가 비활성인 카테고리는 레벨이 오르지 않으므로 이 값과는 관계가 없습니다.
- [_category_](ko/editor/category)
___

## 통화
게임 내에서 사용하는 통화(코인)의 설정
- 게임 내에서 사용되는 통화를 설정합니다. 1개 이상 필요합니다.
- 통화는 여러 개 정의할 수 있으며, 각각을 인포메이션(ID·이름·아이콘·색 등)으로 설정합니다.
- 통화는 아이템의 매매와 용량·대기열의 확장에 사용됩니다.
- 맨 앞의 통화가 메인 통화로 취급되며, 아이템·용량·대기열에서 통화 ID(`coinId`)가 지정되지 않은 경우나 통화 목록에 없는 ID가 지정된 경우에 쓰입니다.
- 통화는 아이템의 일종으로 취급됩니다. 조건이나 보상에서는 여기서 설정한 ID를 아이템으로 참조하세요. 카테고리에는 속하지 않으며, 장비나 매매의 대상이 되지 않습니다.
- [_information_](ko/editor/information)
- [_item_](ko/editor/item)
___

## 용량
인벤토리의 용량 설정
- 플레이어가 소지할 수 있는 아이템의 종류 수 상한을 관리합니다.
- 각 아이템의 소유 수가 아니라, 소지하고 있는 아이템의 종류 수로 관리됩니다.
- `initialCount`를 0으로 하면 용량은 무제한이 되고, 용량의 구입도 할 수 없게 됩니다.
- 조건이나 보상에서 용량의 아이템을 참조할 경우에는 여기서 설정한 ID, 또는 `capacity`를 사용하세요.
- [_item_](ko/editor/item)
___

### [_용량의 인포메이션_](ko/editor/information)
___

### 용량의 초깃값[개]
초기 인벤토리 용량(소지할 수 있는 아이템의 종류 수)
- 게임 시작 시의 초기 용량(소지할 수 있는 아이템의 종류 수)입니다. 기본값은 `10`입니다.
- `0`으로 하면 용량은 무제한이 되고, 동시에 용량의 구입도 할 수 없게 됩니다.
___

### 용량의 기본 가격[코인]
용량을 1개 늘리기 위한 초기 가격
- 인벤토리 용량을 1칸 늘리기 위한 기본 가격(코인)입니다. `1` 이상의 정수로 설정합니다.
- 실제 가격은 '기본 가격 × 증가율^구입한 횟수'로 계산됩니다.
- 예: 기본 가격 100, 증가율 1.2인 경우 1회째 100코인, 2회째 120코인, 3회째 144코인이 됩니다.
___

### 용량의 증가율[배]
용량 확장 비용의 증가율
- 용량 확장의 비용이 n회째 구입에서 얼마나 증가하는지의 배율입니다. 기본값은 `1.2`입니다.
- `1.0`인 경우에는 항상 같은 가격, `1.2`인 경우에는 구입할 때마다 20%씩 비싸집니다.
- 계산식: 기본 가격 × 증가율^구입한 횟수

|증가율|1개째|5개째|10개째|100개째|1000개째|
|-|-|-|-|-|-|
|1.00|x1.00|x1.00|x1.00|x1.00|x1.00|
|1.05|x1.00|x1.22|x1.55|x125.24|x1.5×10²¹|
|1.10|x1.00|x1.46|x2.36|x1.3×10⁴|x2.2×10⁴¹|
|1.20|x1.00|x2.07|x5.16|x6.9×10⁷|x1.3×10⁷⁹|
|1.50|x1.00|x5.06|x38.44|x2.7×10¹⁷|x8.2×10¹⁷⁵|
___

### 용량의 통화 ID
용량 확장에 쓰는 통화의 ID
- 인벤토리 용량의 확장 가격에 쓰는 통화(coins)의 ID를 지정합니다.
- 비워 둔 경우, 또는 통화 목록에 없는 ID를 지정한 경우에는 메인 통화(coins의 맨 앞)가 쓰입니다.
___

### 용량의 구입 상한[회]
용량을 구입할 수 있는 최대 횟수
- 용량을 통화로 구입할 수 있는 횟수의 상한입니다.
- `0`으로 하면 무제한으로 구입할 수 있습니다.
- `-1`로 하면 구입할 수 없게 됩니다.
- 보상에 의한 용량의 증가는 이 상한의 대상 밖입니다.
___

## 대기열
액션의 연속 실행(대기열)의 칸 수 설정
- 액션을 연속 실행하기 위한 대기열의 칸 수를 관리합니다.
- 대기열은 실행 중인 액션을 포함하며, 맨 앞에 있는 액션이 실행됩니다. 칸이 `1`일 때는 실행 중인 것만 있고 대기는 가질 수 없습니다.
- 칸 수는 용량과 마찬가지로 통화로 구입할 수 있는 것 외에, 액션이나 이벤트의 보상에서 대기열의 아이템을 지정해 늘릴 수도 있습니다.
- 조건이나 보상에서 대기열의 아이템을 참조할 경우에는 여기서 설정한 ID, 또는 `queue`를 사용하세요.
- [_item_](ko/editor/item)
___

### [_대기열의 인포메이션_](ko/editor/information)
___

### 대기열의 초깃값[칸]
게임 시작 시의 연속 실행 칸 수
- 게임 시작 시의 대기열 칸 수입니다. 기본값은 `1`입니다.
- 최솟값은 `1`입니다(실행 중인 것이 1칸을 쓰기 때문. 용량과 같은 `0`=무제한의 취급은 없습니다).
___

### 대기열의 기본 가격[코인]
칸을 1개 늘리기 위한 초기 가격
- 연속 실행의 칸을 1개 늘리기 위한 기본 가격(코인)입니다. `1` 이상의 정수로 설정합니다.
- 실제 가격은 '기본 가격 × 증가율^구입한 횟수'로 계산됩니다.
- 예: 기본 가격 100, 증가율 1.2인 경우 1회째 100코인, 2회째 120코인, 3회째 144코인이 됩니다.
___

### 대기열의 증가율[배]
칸 확장 비용의 증가율
- 칸 확장의 비용이 n회째 구입에서 얼마나 증가하는지의 배율입니다. 기본값은 `1.2`입니다.
- `1.0`인 경우에는 항상 같은 가격, `1.2`인 경우에는 구입할 때마다 20%씩 비싸집니다.
- 계산식: 기본 가격 × 증가율^구입한 횟수
- 증가하는 방식은 용량의 증가율과 같습니다. 배율의 기준은 용량의 표를 참조하세요.
___

### 대기열의 통화 ID
칸 확장에 쓰는 통화의 ID
- 연속 실행의 칸의 확장 가격에 쓰는 통화(coins)의 ID를 지정합니다.
- 비워 둔 경우, 또는 통화 목록에 없는 ID를 지정한 경우에는 메인 통화(coins의 맨 앞)가 쓰입니다.

### 대기열의 구입 상한[회]
칸을 구입할 수 있는 최대 횟수
- 연속 실행의 칸을 통화로 구입할 수 있는 횟수의 상한입니다.
- `0`으로 하면 무제한으로 구입할 수 있습니다.
- `-1`로 하면 구입할 수 없게 됩니다.
- 보상에 의한 칸의 증가는 이 상한의 대상 밖입니다.

## 경험치의 상승률[배]
레벨 업 난이도의 증가율
- 카테고리의 레벨이 오름에 따라, 다음 레벨이 되는 데 필요한 경험치의 상승률입니다. 기본값은 `1.05`이며 `1` 미만은 설정할 수 없습니다.
- 이 값을 크게 하면 난이도가 올라갑니다. `1`로 하면 어느 레벨에서든 필요한 경험치가 달라지지 않습니다.
- 다음 레벨이 되는 데 필요한 경험치는 (경험치의 상승률)^(현재 레벨-1)입니다. 레벨은 소수를 버리고 셉니다.
- 상한(카테고리의 최대 레벨)에 도달한 뒤의 경험치는 버려집니다.

|경험치의 상승률|Lv.1|Lv.2|Lv.10|Lv.50|Lv.99|
|-|-|-|-|-|-|
|1.00|x1.00|x1.00|x1.00|x1.00|x1.00|
|1.02|x1.00|x1.02|x1.20|x2.64|x6.96|
|1.05|x1.00|x1.05|x1.55|x10.92|x119.28|
|1.10|x1.00|x1.10|x2.36|x106.72|x1.1×10⁴|
|1.20|x1.00|x1.20|x5.16|x7583.70|x5.8×10⁷|

## 액션 레벨 제한
액션의 실행에 특성의 카테고리의 레벨을 요구
- 활성일 경우, 각 액션의 조건(requirements) 맨 앞에 '특성의 카테고리의 레벨이 그 액션의 레벨 이상일 것'이라는 조건이 자동으로 추가됩니다.
- 특성(attribute)이 설정되어 있지 않은 경우에는 속한 카테고리가 쓰입니다.
- 특성의 카테고리의 수치(numeric)가 비활성인 경우에는 레벨이 오르지 않으므로 추가되지 않습니다.
- 추가된 조건은 월드를 읽어 들일 때 써넣어지므로, 플레이어의 화면에서도 일반 조건과 똑같이 표시됩니다.
- [_action_](ko/editor/action)
- [_category_](ko/editor/category)
- [_requirement_](ko/editor/requirement)

## 속성의 배율[배]
레벨 차 10마다 속성이 몇 배가 되는지
- 카테고리의 레벨과 액션의 레벨의 차가 `10` 벌어질 때마다 속성이 몇 배가 되는지를 설정합니다. 기본값은 `1.5`이며 `1` 미만은 설정할 수 없습니다.
- 배율은 (속성의 배율)^(레벨 차÷10)으로 계산됩니다. 레벨 차가 `0`일 때는 `1`배가 되며, 액션에 설정한 값이 그대로 쓰입니다.
- 공격과 경험치는 이 배율만큼 증가하고, 방어(받는 피해)와 속도(소요 시간)는 같은 배율만큼 감소합니다.
- 명중·회피·성공 확률·회복량은 `0`〜`100`% 안에 들어가는 값이므로, 이루어지는 쪽과 이루어지지 않는 쪽의 비에 배율이 곱해집니다. `0`%와 `100`%는 변화하지 않으며, 중간의 값이 `100`%를 넘는 일도 없습니다.
- 방어·회피·속도는 배율의 작용이 절반입니다(레벨 차 `20`에서 다른 속성의 레벨 차 `10`만큼이 됩니다). 방어와 회피는 피격률과 받는 피해에 이중으로 곱해지고, 속도는 실행 횟수로서 다른 모든 속성에 곱해지므로, 작용을 약하게 해서 균형을 맞추고 있습니다.
- 기준은 (경험치의 상승률)의 `6.7`제곱입니다. 이를 넘으면 레벨이 오를수록 레벨 업이 가속되고, 밑돌수록 후반의 레벨 업에 시간이 걸리게 됩니다.
- `1`로 하면 레벨 차의 영향이 없어집니다. 값을 크게 하면 레벨 차에 따른 유불리가 급격해집니다.

|속성의 배율|레벨 차 -20|레벨 차 -10|레벨 차 0|레벨 차 +10|레벨 차 +20|
|-|-|-|-|-|-|
|`1`|`x1.00`|`x1.00`|`x1.00`|`x1.00`|`x1.00`|
|`1.5`|`x0.44`|`x0.67`|`x1.00`|`x1.50`|`x2.25`|
|`2`|`x0.25`|`x0.50`|`x1.00`|`x2.00`|`x4.00`|
|`3`|`x0.11`|`x0.33`|`x1.00`|`x3.00`|`x9.00`|
