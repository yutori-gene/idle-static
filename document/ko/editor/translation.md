
# 번역
월드의 문구를 10개 언어로 번역하기 위한 설정
- 번역에는 화면의 공통 문구(프리셋)의 번역과, 월드 자체가 가진 이름·설명문의 번역 두 종류가 있습니다.
- 화면 공통 문구의 번역은 일반의 `translations` 설정과 관계없이 항상 동봉됩니다. 제작자가 준비할 필요는 없습니다.
- 월드 자체의 번역은 일반의 `translations`를 활성화하여 공개했을 때만 내보내지며, 제작자가 번역합니다.
- 번역을 준비하지 않은 언어에서는 월드에 적힌 그대로의 문장이 표시됩니다.
- [_general_](ko/editor/general)
___

## 번역의 활성화
번역을 활성화했을 때의 동작
- 활성화하는 것은 일반의 `translations`입니다. 여기서는 그것을 활성화했을 때 무슨 일이 일어나는지 설명합니다.
- 활성화한 경우, 공개한 월드에 10개 언어분의 번역 파일이 동봉되어 플레이어의 설정에서 언어를 전환할 수 있게 됩니다. 비활성화한 경우에는 언어 전환 자체를 할 수 없습니다.
- 10개의 파일은 같은 내용(번역 전의 문장)으로 내보내집니다. 번역하지 않은 언어는 원래의 문장이 그대로 표시됩니다. 일부 언어만 번역할 수도 있지만, 그 언어의 화면에는 원래의 문장이 섞입니다.
- 게임을 시작했을 때는 일반의 `language`에서 설정한 언어가 먼저 표시됩니다. 그 후 설정 칼럼에서 원하는 언어로 변경할 수 있습니다.
- 에디터의 테스트 플레이에서는 월드의 번역 파일이 아직 존재하지 않기 때문에, 언어를 전환해도 바뀌는 것은 화면의 공통 문구뿐입니다.
- 번역 작업은 번거롭지만, 더 많은 사람이 즐길 수 있게 됩니다.
- [_general_](ko/editor/general)
___

## 언어 파일
내보내지는 번역용 JSON 파일
- 메뉴의 공개로 월드를 내보내면 `translations/base`에 화면 공통 문구의 번역이, `translations/world`에 월드 자체의 번역이 들어갑니다.
- 번역할 것은 `translations/world`의 10개 파일뿐입니다. `translations/base`는 번역된 것이 동봉되므로 손댈 필요가 없습니다.
- 파일의 내용은 타입별로 나뉘어 있고, 그 아래에 요소의 ID, 다시 그 아래에 이름(`name`)과 설명문(`explanation`)이 늘어섭니다.
- 타입은 카테고리·액션·아이템·이벤트·그룹·스킬·프리셋의 7종류입니다. 통화·용량·대기열은 아이템에, 월드의 개요는 프리셋에, 과제와 고정 이벤트는 함께 이벤트에 들어갑니다.
- 이름을 비워 둔 요소는 ID에서 자동으로 만들어진 이름이 내보내집니다.
- 번역한 파일은 같은 이름 그대로 `translations/world`에 다시 놓습니다.
___

## 번역 작업
번역 데이터의 편집 작업
- 내보내진 10개의 파일은 모두 같은 내용(번역 전의 문장)입니다.
- 원래 언어의 파일 외에는 번역 작업이 필요합니다.
- 번역하는 것은 `name`과 `explanation`의 값뿐입니다. ID나 JSON의 구조는 바꾸지 마세요.
___

### AI
AI를 이용한 번역
- ChatGPT, Copilot, Claude 등의 AI를 이용해 번역합니다.
- 한 번에 번역할 수 있고, 어느 정도 품질의 번역이 가능합니다.
- 완전한 번역이 되지 않는 경우가 있으며, 특히 전문 용어나 고유 명사의 번역에는 주의가 필요합니다.
- 번역량에 따라서는 AI 이용에 비용이 드는 경우가 있습니다.
- 도중에 AI의 번역 진행이 중단되었을 때 '계속해'라고 지시하면 어떻게든 되는 경우가 있습니다. (어떻게든 되지 않는 경우도 있습니다.)
___

#### 프롬프트 예
AI에 주는 번역 지시의 예
- 프롬프트의 예: 업로드한 JSON 데이터의 `name`과 `explanation`의 값을 일본어에서 영어로 번역해 주세요. 키와 그 밖의 부분은 변경하지 마세요.
___

#### GPT의 이용
ChatGPT의 GPT를 이용한 번역
- ChatGPT에서 제공되는 GPT 라이브러리의 JSON Language Translator를 이용하면 JSON 번역을 편하게 할 수 있습니다.
- JSON의 구조가 유지된 채로 번역됩니다.
- ChatGPT 이외의 AI 서비스에서도 같은 기능이 제공되는 경우가 있습니다.
___

### 번역 서비스
번역 서비스의 이용
- DeepL, Google 번역 등의 온라인 서비스를 이용해 번역합니다.
- AI 번역보다 높은 품질의 번역을 기대할 수 있지만, 번역량에 따라서는 요금이 발생합니다.
- JSON 파일을 그대로 번역 서비스로 번역할 수는 없기 때문에, 프로그램을 만들어 이용해야 합니다.
- 유료이지만, JSON 데이터 그대로 번역되는 서비스도 있는 듯합니다. (doctranslator.com 등)
___

### 수동
수동에 의한 번역
- 번역 파일을 텍스트 에디터로 열어 각 언어로 번역한 내용을 입력합니다. 매우 손이 많이 가지만, 원하는 대로 번역할 수 있습니다.
