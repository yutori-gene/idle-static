
# 획득
아이템과 카테고리 레벨의 취득 설정
- 취득물을 설정합니다.
- 아이템 외에 카테고리의 레벨, 액션의 실행 횟수를 변경할 수 있습니다.
- 입수 확률을 설정할 수 있습니다.

|타입|획득하는 것|
|-|-|
|카테고리|레벨|
|액션|실행 횟수|
|아이템|소지 수|
- [_type_](ko/editor/type)
___

## 타입
취득하는 요소의 종류

|타입|획득되는 것|
|-|-|
|카테고리|레벨(설정한 값이 그대로 더해집니다)|
|액션|실행 횟수|
|아이템|소지 수|
___

## 요소의 ID
취득할 요소를 식별하는 ID
___

## 값
취득하는 수치
- 마이너스 값을 설정하면 소지 수나 실행 횟수, 레벨을 감소시킵니다. 다만 0 미만이 되지는 않습니다.
- 아이템에 최대 소유 수(maximum)가 설정되어 있는 경우, 그 값을 넘어 소유 수가 늘지 않습니다.
- 타입이 카테고리인 경우, 설정한 값이 그대로 레벨에 더해집니다(1이면 1레벨). 액션의 경험치 설정으로 조정하는 것이 일반적인 방법입니다. 특수한 목적이 없다면 이 설정은 필요 없습니다.
- 카테고리의 레벨은 0 미만이 되지 않으며, 일반의 `maxCategoryLevels`(카테고리의 최대 레벨)를 넘지도 않습니다.
- 값은 정수로 설정합니다.
___

## 확률[-1~1]
취득이 성공할 확률(음수는 실패 시에만 평가)
- 입수할 확률을 -1에서 1까지의 소수로 설정합니다. 확률 판정에는 절댓값이 사용됩니다.
- 값이 양수일 때는 액션 성공 시에만 평가되며, `1`이면 반드시 입수하고 `0.5`면 50% 확률로 입수합니다.
- 값이 음수일 때는 액션 실패 시에만 평가되며, `-1`이면 반드시 입수하고 `-0.5`면 50% 확률로 입수합니다.
- `0`에서는 성공 시에도 실패 시에도 입수하지 않습니다.
- 기본값은 `1`(성공 시 반드시 입수)입니다.
