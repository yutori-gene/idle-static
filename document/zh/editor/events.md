
# 事件
汇总了任务、变化事件、固定事件的、世界的全部事件
- 世界的事件由任务（tasks）、变化事件（changed）、固定事件（unique）3种构成。
- 任务是满足条件即达成的使命。
- 变化事件是以数量的增加为契机反复发动的、不显示在画面上的内部处理用事件。
- 固定事件是每个时机各准备1个、无法追加和删除的框位。

|种类|说明|
|-|-|
|[_task_](zh/editor/task)|满足条件即达成的使命|
|[_changed_](zh/editor/changed)|类别・动作・物品的数量一次增加达到条件量以上时发动的内部处理用事件|
|[_unique_](zh/editor/unique)|在固定的时机发动的消息与奖励|
