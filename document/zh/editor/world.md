
# 世界
整个游戏世界的设置与数据结构
- 这是用运行器读取来游玩的、游戏的定义数据。
- 通过设置可以制作出如你所愿的放置类游戏。
- 世界包含基本设置，以及类别、动作、物品、技能、分组、预设这6种类型，还有事件。
