
# 组件
通用的部件
- 各处设置中使用的通用部件会被抽出后统一处理。
- 无论在哪一处使用的组件都是通用的，但根据所在之处，组件中也有不被使用的项目。

|组件|说明|
|-|-|
|[_information_](zh/editor/information)|要素的基本信息（ID、名称、说明文、图标、颜色）的设置|
|[_requirement_](zh/editor/requirement)|要素的使用与显示所需的条件设置|
|[_acquisition_](zh/editor/acquisition)|物品和类别等级的取得设置|
|[_combat_](zh/editor/combat)|stamina 类型的动作中战斗补正值的设置|
|[_property_](zh/editor/property)|物品所具有的效果的设置|
