
# 放置类游戏开发平台
从名为世界的定义数据出发，制作并游玩放置类游戏的平台
- 游戏的内容汇总在称为「世界」的定义数据中。即使不编写程序，仅靠编辑器的输入也能组建出一款游戏。
- 制作好的世界可以在运行器中加载游玩。若导出为可独立运行的形式，也能直接分发。
- 本文档由编辑器和运行器两部分构成。制作世界一侧的设置项请参阅编辑器，游玩一侧的画面请参阅运行器。
___

## 特征
平台的主要功能与特征
- 放置类游戏所需的要素（类别、动作、物品、技能、分组、预设）和事件从一开始就已备齐，仅靠组合即可决定游戏的形态。
- 关闭画面期间的时间也会作为离线进度被消化，因此放置多久就会推进多少。
- 支持10种语言。界面的通用语句始终随附，世界自身的文本也可以按语言分别准备。
- 进度会按世界分别保存在浏览器中，也可以导出为文件带走。
