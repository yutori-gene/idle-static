
# Eigenschaft
Die Zahlen, die das Ergebnis einer Aktion beeinflussen
- Eine Eigenschaft ist eine numerische Anpassung, die das Ergebnis einer ausgeführten Aktion beeinflusst
- Aus einer Kategorie geöffnet, zeigt es die Liste der beitragenden Gegenstände, aus einem Gegenstand die Liste der betroffenen Kategorien und aus einer Fähigkeit nur die Anpassungswerte
___

## Eigenschaftsliste
Die Liste der Eigenschaften, die zu dieser Kategorie gehören
- Eine Eigenschaft ist ein Element, das die Ausführung von Aktionen beeinflusst
- Die Tags darunter sind die Gegenstände, die zu diesem Wert beitragen, samt Aufschlüsselung
- Auch ein Gegenstand aus einer anderen Kategorie wirkt, wenn diese Kategorie sein Ziel ist
___

## Berechnung
Die auf eine Aktion angewandten Werte der Eigenschaften und ihre Aufschlüsselung
- Der angewandte Wert wird nicht addiert oder subtrahiert: Je 10 Level Unterschied greift ein Faktor. Angriff und Erfahrung steigen, Verteidigung und benötigte Zeit sinken
- Wie stark es wirkt, ist bei jeder Eigenschaft anders
- Genauigkeit, Ausweichen, Erfolgsrate und Erholung gehen nie unter 0 % oder über 100 %
