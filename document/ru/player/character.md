
# Персонаж
Просмотр положения главного героя и управление им
- Столбцы, выстроенные здесь, служат для того, чтобы охватить всё целиком поверх категорий.
- Открывается по заголовку персонажа в верхнем столбце.
___

## Активность
Список действий, которые можно выполнить, сгруппированных по категориям
- Действие — это поведение, которое при выполнении даёт опыт и награды
- Долгое нажатие на полосу переключает выполнение
- Lv.n — это уровень, требуемый для этого действия
___

## Инвентарь
Список предметов, которые у вас есть, сгруппированных по категориям
- Предмет — это элемент, связанный с тем, что вы носите: снаряжением, расходуемыми и ценными вещами
- Долгое нажатие на полосу переключает снаряжение
- Ячейки хранения считают виды предметов, а не их количество
___

## Продажа
Выбор имеющихся у вас предметов из списка и продажа их разом
- Здесь перечислены только имеющиеся предметы, у которых задана цена продажи
- При выборе продаётся всё имеющееся количество. Значение — это общая сумма
- Снаряжение, количество которого после продажи стало нулевым, снимается автоматически
___

## Состояние
Показ текущего состояния, включая поправки, применённые к категории
- Свойство — это числовая поправка, влияющая на результат выполнения действия
- Здесь перечислены только поправки от предметов; в зависимости от выполняемого действия добавляются и другие поправки, например от навыков
- У предметов, которые не нужно надевать, поправка растёт пропорционально количеству
___

## Способность
Список навыков, которые могут сработать сейчас, сгруппированных по категориям
- Навык — это элемент, который при срабатывании в бою изменяет боевые значения только на этот ход
- Здесь перечислены навыки надетых предметов и имеющихся предметов, которые не нужно надевать
- Доля — это вероятность срабатывания
___

## Миссии
Список задач всех категорий и того, насколько они выполнены
- Задача — это событие, которое достигается при выполнении условий. Награду вы получаете сами
- Достигнутые задачи отмечены галочкой. Достигнутая однажды задача остаётся достигнутой, даже если условия перестают выполняться
- Задачи, награда за которые ещё не получена, отмечены лентой. Откройте и нажмите Получить
