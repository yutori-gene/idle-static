
# Свойство
Числа, влияющие на результат действия
- Свойство — это числовая поправка, влияющая на результат выполнения действия
- При открытии из категории показывается список вносящих вклад предметов, из предмета — список затрагиваемых категорий, из навыка — только значения поправок
___

## Список свойств
Список свойств, относящихся к этой категории
- Свойство — это элемент, влияющий на выполнение действий
- Теги ниже — это предметы, вносящие вклад в это значение, и их разбивка
- Предмет из другой категории тоже действует, если его целью является эта категория
___

## Расчёт
Значения свойств, применённые к действию, и их разбивка
- Применённое значение не складывается и не вычитается: на каждые 10 уровней разницы накладывается множитель. Атака и опыт растут, а защита и требуемое время уменьшаются
- То, насколько это влияет, различается у каждого свойства
- Точность, уклонение, вероятность успеха и восстановление не опускаются ниже 0 % и не превышают 100 %
