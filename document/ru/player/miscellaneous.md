
# Дополнения
Столбцы, не относящиеся к какому-либо определённому типу
- Столбцы событий и групп открываются справа с любого уровня.
- Столбец языка открывается из столбца настроек и из столбца приветственного события.

## Группа
Классификация, объединяющая категории, действия и предметы
- Группа — это классификация, объединяющая категории, действия и предметы
- В одной группе можно снарядить только один предмет
- Значение справа — это уровень для категорий, требуемый уровень для действий и количество для предметов
___

## Язык
Смена языка, используемого для отображения
- Меняется только язык интерфейса
- Тексты без перевода отображаются на языке по умолчанию
