
# Платформа для разработки idle-игр
Платформа для создания idle-игр из данных определения, называемых миром, и для игры в них
- Содержимое игры собрано в данных определения, которые называются «миром». Даже не написав ни строчки кода, вы можете собрать целую игру одним лишь вводом в редакторе.
- Созданный мир загружается и запускается в плеере. Если экспортировать его в виде, работающем самостоятельно, его можно распространять как есть.
- Этот документ состоит из двух частей: редактор и плеер. Настройки для создания мира смотрите в разделе редактора, а экраны для игры — в разделе плеера.
___

## Особенности
Основные возможности и особенности платформы
- Элементы, нужные idle-игре (категории, действия, предметы, навыки, группы и пресеты), и события подготовлены с самого начала, и облик игры определяется одним лишь их сочетанием.
- Время, пока экран закрыт, тоже расходуется как офлайн-прогресс, поэтому игра продвигается ровно настолько, насколько вы её оставили.
- Поддерживаются десять языков. Общие фразы интерфейса включены всегда, а текст самого мира можно подготовить для каждого языка.
- Прогресс сохраняется в браузере отдельно для каждого мира, его можно экспортировать в файл и унести с собой.
