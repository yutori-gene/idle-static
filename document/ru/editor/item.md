
# Предмет
Элементы вещей: снаряжения, расходуемого и тому подобного
- Это элементы, связанные с владением вещами: снаряжением, расходуемым, ценностями и тому подобным.
- Ячейки снаряжения создаются по группам для каждой категории, и из предметов одной ячейки можно снарядить только один. Предмет можно сделать и таким, что его нельзя снарядить.
- Так как количество во владении само по себе является прогрессом, предмет можно использовать и как флаг или счётчик. Если сделать предмет без эффекта, который к тому же нельзя снарядить, получится элемент, который просто считает число.

## Категория
ID категории, к которой относится предмет
- Укажите ID категории, к которой относится этот предмет. Он выстраивается в списке предметов указанной категории, и ячейки снаряжения тоже создаются для каждой категории.
- Если цвет не задан у самого предмета, он наследует цвет категории.
- Цель, на которую распространяются эффекты свойств, можно указать отдельно от категории, к которой предмет относится, поэтому эффект может давать и предмет другой категории.
- [_category_](ru/editor/category)
- [_property_](ru/editor/property)
___

## Группа
Классификация предмета по группе отображения
- Примените одну из тех, что определены в группах непосредственно под миром.
- Список предметов показывается в порядке заданных групп.
- Если оставить пустым, разделения на группы нет.
- [_group_](ru/editor/group)
___

## Начальное состояние открытия
Начальное состояние отображения и открытия элемента (при выполнении условий срабатывания он автоматически переходит в более высокое состояние)
- secreted: Пока не соблюдены все requirements, он вовсе не появляется в интерфейсе (не показывается и в подсказках, а в списках условий и наград он скрыт).
- hidden: Пока на него не ссылается ни один открытый элемент и его условия не выполнены, он полностью скрыт (имя тоже блёклое, взаимодействие невозможно).
- hinted (по умолчанию): Заранее показывается только имя, но до открытия взаимодействовать нельзя.
- released: Он открыт и доступен с самого начала, независимо от условий (прежнее «показывать с самого начала»).
- Если предмет хоть раз получен, он остаётся открытым независимо от этой настройки и условий.
- И наоборот, предмет, у которого не задано ни одного условия, не открывается, пока его не получат, если только не поставить `released`. Для предметов, которые вы хотите продавать игроку, обязательно задавайте условия.

## Цена покупки [Монеты]
Настройка цены покупки предмета
- Это количество валюты, которое вы платите при покупке одной штуки предмета. Значение по умолчанию — `-1` (купить нельзя).
- Неоткрытый предмет купить нельзя, даже если цена задана.
- Количество, которое можно купить за раз, — это меньшее из того, что можно купить на имеющуюся валюту, и остатка до максимального количества во владении.

|Цена покупки|Как обрабатывается|
|-|-|
|0|Купить нельзя|
|Значение больше 0|Цена, по которой можно купить|
|Значение меньше 0 (например, -1)|Купить нельзя (обрабатывается как 0)|
___

## Цена продажи [Монеты]
Настройка цены продажи предмета
- Это количество валюты, которое вы получаете при продаже одной штуки предмета. Значение по умолчанию — `0` (продать нельзя).
- Получаемая валюта — та же, что и при покупке: указанная в ID торговой валюты.
- Автоматически из цены покупки она не выводится, поэтому, если хотите, чтобы предмет можно было продать, обязательно задайте значение.
- Отрицательные значения задать нельзя.

|Цена продажи|Как обрабатывается|
|-|-|
|0|Продать нельзя|
|Значение больше 0|Можно продать по этой цене|
___

## Максимальное количество во владении [Штуки]
Ограничение максимального количества предмета во владении
- При 0 количество, которым можно владеть, не ограничено. Значение по умолчанию — `0`.
- При 1 и больше владеть можно только до этого числа. При достижении предела количество во владении не растёт, даже если получить ещё.
- Оно же становится пределом количества, которое можно купить.
- Если количество во владении в сохранении превышает предел, при загрузке оно уменьшается до предела.
___

## Тип снаряжения
Настройка типа, определяющая снаряжение, эффект и расход предмета
- У предметов `necessary` и `consumable` их группа автоматически становится ячейкой снаряжения категории.
- Внутри одной группы снарядить можно только один предмет. При снаряжении нового предмета имеющееся снаряжение той же группы снимается автоматически.
- Порядок ячеек снаряжения следует порядку определения в списке групп мира.
- `unnecessary` даёт эффект независимо от того, снаряжён он или нет, и величина эффекта пропорциональна количеству во владении (при 0 эффекта нет, при n штуках — в n раз больше).
- `consumable` расходуется только тогда, когда свойства этого предмета влияют на выполненное действие, по одной штуке за действие. На действиях, до которых его эффект не доходит, он не убывает.
- Предмет, израсходованный до 0, снимается автоматически.
- Чтобы снарядить его, нужно, чтобы были соблюдены и условия самого предмета, и условия категории.

|Значение|Снаряжение|Проявление эффекта|Расход|Пример|
|-|-|-|-|-|
|`necessary`|Нужно|Только пока снаряжён (за одну штуку)|Не расходуется|Снаряжение: мечи, доспехи и тому подобное|
|`consumable`|Нужно|Только пока снаряжён (за одну штуку)|Расходуется при выполнении действия|Предметы, которые расходуют ради эффекта, например зелья|
|`unnecessary`|Не нужно|Всегда, пока во владении (пропорционально количеству во владении)|Не расходуется|Пассивные предметы, которые дают эффект просто от наличия|
|`impossible`|Нельзя|Нет|Не расходуется|Предметы без эффекта: материалы, хлам и тому подобное|

## ID торговой валюты
ID валюты, используемой для торговли этим предметом
- Укажите ID валюты (coins), общей для цены покупки и цены продажи.
- Если оставить пустым или указать ID, которого нет в списке валют, используется основная валюта (первая в coins).
