
# Обзор
Базовые сведения о мире и сведения об авторе
- Это поля, которые описывают содержание мира.
- Задайте их так, чтобы они были понятны, когда пользователь выбирает мир.
- Кроме URL, эти настройки не влияют на ход игры.
___

## [_Информация_](ru/editor/information)
___

## Версия
Номер версии мира
- Введите число от `0` и выше (целое или дробное). Значение по умолчанию — `0`.
- Обычно целая часть обозначает старшую версию, а дробная — младшую.
- Версия разработки (development) — это версия редактора, то есть нечто иное.
___

## Имя автора
Имя автора мира
- Введите сетевое имя или прозвище.
- Оно должно быть от 3 до 20 символов, и в нём можно использовать только полуширинные буквы и цифры, пробелы и `!` `?` `.` `,` `-`.
___

## Домашняя страница
URL сайта автора
- Если у вас есть собственная домашняя страница или соцсети, введите их URL.
- Игрок может посмотреть этот URL по ссылке.
- Если такого нет, оставьте поле пустым. Начальное значение — `https://`.
___

## URL
URL игры
- Введите URL, по которому размещается игра этого мира.
- Введите URL главной страницы вроде index.html вместе с доменом.
- Это поле для записи того, где размещён мир. Если место размещения ещё не выбрано, оставьте поле пустым.
- Опубликованный мир работает как PWA. PWA — это возможность установить его и работать как приложение, в которое можно играть и без сети.
- Настройки PWA создаются с относительными путями, поэтому он работает как есть там, где размещён, независимо от значения этого поля.
___

## Предполагаемое время игры
Ориентировочное время до прохождения мира
- Это предполагаемое время игры, нужное, чтобы пройти мир до конца.
- Игрок может посмотреть его как ориентир, когда играет.
- Это лишь справочное время, и чёткого определения того, что считать завершением мира, нет.
___

### Значение
Число времени игры
- Задаётся целым числом от `1` и выше. Значение по умолчанию — `1`.
___

### Единица
Единица времени (часы, минуты и тому подобное)
- Выбирается из секунд, минут, часов, дней, лет, веков и бесконечности. Значение по умолчанию — дни.
- Бесконечность используется для миров, у которых нет конца.
