
# Задача
Миссия, которая считается выполненной при соблюдении условий
- Она считается выполненной, когда заданные вами условия соблюдены, и в верхней части экрана показывается сообщение.
- Она показывается в списке миссий плеера и в списке задач категории.
- Задача без заданных условий никогда не выполняется.
- После выполнения она остаётся выполненной, даже если условия потом перестают соблюдаться, и награду можно получить в любой момент.
- Награда не выдаётся автоматически. Игрок получает её, когда открывает задачу и нажимает полосу Получение.
- Пока награда не получена, на полосе в списке есть лента, показывающая, что её ещё не забрали.
- Задача без заданной награды не показывает полосу Получение и завершается в момент выполнения.
- Пока число видов предметов, которые вы можете держать, на пределе, награду получить нельзя. Разберите запасы и заберите её снова.
- С помощью получения можно изменять уровень категории, число выполнений действия и количество предмета во владении.
- То, что вы хотите запускать не по условиям, а в другой момент — при первом запуске, при завершении игры и так далее, — задаётся фиксированным событием (unique).

## Категория
ID категории, к которой относится задача
- Укажите ID категории, к которой относится эта задача.
- Если он задан, на экран категории в плеере добавляется список задач, а в списке миссий они тоже показываются сгруппированными по категориям.
- Если оставить пустым, задача не относится ни к одной категории и показывается вместе в начале списка миссий.
- Если цвет не задан у самой задачи, она наследует цвет категории.
- [_category_](ru/editor/category)
___

## Момент
Момент срабатывания задачи (фиксировано `tasked`)
- У задачи зафиксировано `tasked` (когда заданные вами условия соблюдены), и это нельзя изменить.
- Награду можно получить только один раз, и после получения задача остаётся выполненной без дальнейших изменений.
- То, что вы хотите запускать в другой определённый момент, задаётся фиксированным событием (unique).
- [_unique_](ru/editor/unique)
___

## Начальное состояние отображения
Начальное состояние отображения значка задачи (выполнение определяется условиями, и эта настройка его не выполняет)
- Условия выполнения задачи определяются requirements, а это поле влияет только на вид значка в списке.
- secreted: Пока не соблюдены все requirements, задача вовсе не появляется в списке задач (само выполнение всё равно происходит по условиям).
- hidden и hinted: Значок показывается перечёркнутым, как ещё не открытый.
- released: Черта исчезает, и он показывается как уже открытый.
- Однажды выполненная задача не исчезает из списка и продолжает показываться как выполненная, даже если условия потом перестают соблюдаться.

## Групповой подсчёт
Принимает id в условиях за ID группы и оценивает по суммарному значению элементов, которые к ней относятся
- При включении id, заданный в условиях (requirements), считается ID группы, расположенной непосредственно под миром.
- Условие с типом категории оценивается по сумме уровней всех категорий, которые относятся к этой группе.
- Условие с типом действия оценивается по сумме числа выполнений всех действий, которые относятся к этой группе.
- Условие с типом предмета оценивается по сумме количества во владении всех предметов, которые относятся к этой группе.
- Элементы, которые не открыты (любое состояние, кроме released), в сумму не входят.
- Вероятность расхода (chance) и условие снаряжения (equipment) предмета игнорируются, и количество во владении тоже не расходуется. Они используются только для оценки.
- При выключении id в условиях, как и раньше, считается ID отдельной категории, действия или предмета.

## Группа задач
Классификация задачи по группе отображения
- Примените одну из тех, что определены в группах непосредственно под миром.
- В списке задач категории они показываются разделёнными по группам, с заголовком у каждой. Задачи без заданной группы тоже образуют один блок, и для его заголовка используется пресет «Задача».
- В списке миссий они не разделяются заголовками, по группам собирается только порядок, в котором они выстроены.
- Порядок, в котором выстраиваются блоки, определяется позицией, где впервые появляется задача этой группы.
- [_group_](ru/editor/group)
