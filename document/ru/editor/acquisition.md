
# Получение
Настройка получения предметов и уровней категорий
- Задайте то, что получается.
- Кроме предметов можно менять уровень категории и число выполнений действия.
- Можно задать вероятность получения.

|Тип|Что получается|
|-|-|
|Категория|Уровень|
|Действие|Число выполнений|
|Предмет|Количество во владении|
- [_type_](ru/editor/type)
___

## Тип
Вид элемента, который получается

|Тип|Что получается|
|-|-|
|Категория|Уровень (заданное значение прибавляется как есть)|
|Действие|Число выполнений|
|Предмет|Количество во владении|
___

## ID элемента
ID, определяющий получаемый элемент
___

## Значение
Получаемое число
- Если задать отрицательное значение, количество во владении, число выполнений или уровень уменьшатся. Однако ниже 0 они не опускаются.
- Если у предмета задано максимальное количество во владении (maximum), количество во владении не растёт сверх этого значения.
- Если тип — категория, заданное значение прибавляется к уровню как есть (1 — это один уровень). Обычно это настраивают через настройку опыта у действия. Без особой цели эта настройка не нужна.
- Уровень категории не опускается ниже 0 и не превышает `maxCategoryLevels` в общих настройках (максимальный уровень категории).
- Значение задаётся целым числом.
___

## Вероятность [-1 … 1]
Вероятность успешного получения (отрицательное значение проверяется только при неудаче)
- Задайте вероятность получения десятичным числом от -1 до 1. Для проверки вероятности берётся абсолютное значение.
- При положительном значении проверка идёт только при успехе действия: при `1` предмет достаётся всегда, при `0.5` — с вероятностью 50%.
- При отрицательном значении проверка идёт только при неудаче действия: при `-1` предмет достаётся всегда, при `-0.5` — с вероятностью 50%.
- При `0` предмет не достаётся ни при успехе, ни при неудаче.
- Значение по умолчанию — `1` (при успехе достаётся всегда).
