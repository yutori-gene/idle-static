
# Информация
Настройка основных сведений об элементе (ID, название, описание, значок и цвет)
- Это поля основных сведений, общие для всех элементов мира (категории, действия, предмета, группы, события, навыка и пресета).
- Они задаются отдельно для каждого элемента.
___

## Идентификатор
Уникальный ID, определяющий элемент
- Это ID, который однозначно определяет каждый элемент.
- Это строка, по которой редактор различает элемент.
- Например, какой предмет достанется по завершении действия, указывается через ID.
- Использовать можно сочетание латинских букв, дефисов и цифр, от 1 до 100 символов.

!> После того как игра распространена, не меняйте уже заданный ID. Если поменять, он перестанет совпадать с существующими игровыми данными и игра перестанет работать правильно.
___

### Отображаемое название
Отображаемое имя, создаваемое из ID автоматически
- Если название не задано, дефисы заменяются пробелами, а каждое слово приводится к заглавной первой букве и строчным остальным и показывается как название.
- Даже если в ID есть заглавные буквы, всё кроме первой буквы переводится в строчные.
- Для языков кроме английского поле названия нужно задавать отдельно.
___

#### Пример
Наглядный пример преобразования ID
- Если задать ID `stylish-strong-axe`, названием станет `Stylish Strong Axe`.
- Если задать ID `stylish-STRONG-axe`, названием точно так же станет `Stylish Strong Axe`.
___

### Не повторяться
Запрет на повтор ID внутри одного типа
- Поскольку он служит для различения элементов, не повторяйте его внутри каждого из типов: категории, действия, предмета, группы, события, навыка и пресета.
- События считают задачи, события изменения и фиксированные события одним общим типом, поэтому не повторяйте ID и между ними.
- Одинаковый ID в разных типах — не проблема.
- Мир с повторами выдаёт ошибку при проверке.
- [_type_](ru/editor/type)
___

## Название
Отображаемое название элемента
- Это название элемента, которое показывается в игре.
- Вводить можно и языки кроме английского.
- Название, совпадающее с другим элементом, тоже допустимо.
- Ввести можно до 20 символов.
- Если оно не помещается по ширине показа, выходящая часть сокращается знаком `…`.
___

### Автоматическое преобразование из ID
Функция автоматического создания названия из ID
- Если оставить пустым, оно показывается автоматически на основе ID. Подробности — в предыдущем разделе.
___

## Описание
Подробное описание элемента
- Это описание элемента, которое показывается в игре.
- Вводить можно и языки кроме английского. Даже длинный текст показывается целиком.
- Если описания нет, оставьте пустым.
___

## Значок
Настройка значка, обозначающего элемент
- В качестве значка можно задать изображение, Iconify или эмодзи.
- Iconify — это сервис, который предоставляет значки самых разных видов.
- Если задать несколько из них, они показываются по приоритету: изображение, Iconify, эмодзи.
___

### Изображение
Использование любого файла изображения
- Это изображение, обозначающее элемент.
- При загрузке оно автоматически уменьшается до 60×60 пикселей и сжимается заново.
- Если заданы Iconify или эмодзи, оно не нужно.
___

#### Виды файлов
Поддерживаемые форматы файлов изображений
- Подходят обычные виды, которые способен показать браузер.
- JPEG, PNG, GIF, WebP, SVG и подобные.
- GIF и AVIF преобразуются в PNG. JPEG и WebP уменьшаются с сохранением исходного формата.
- SVG встраивается как есть, без уменьшения, поэтому избегайте файлов большого размера.
___

### Iconify
Использование наборов значков Iconify
- Это значок, обозначающий элемент.
- Если задано изображение, в первую очередь показывается оно.
___

#### Как искать значок
Как выбрать значок в Iconify
- Значки, которые можно показать, ищите в `Iconify`.
- Поиск по значкам сразу находит самый подходящий значок.
- При выборе значка показывается его идентификатор вроде `game-icons:sword-wound` (вид набора значков `:` название значка) — вставьте его как есть в это поле значка.
![iconify-selection.png](../../resources/iconify-selection.png)
- [_iconify_](https://icon-sets.iconify.design)
___

### Эмодзи
Показ значка при помощи эмодзи
- Показывает эмодзи как значок.
- Введите эмодзи Unicode как есть.
- Используется эмодзи, установленный в среде выполнения, поэтому у разных пользователей вид немного различается.
- В Iconify можно задать эмодзи, не зависящие от конкретной среды
- Показать можно и символы кроме эмодзи, но если символов несколько, отображение может поехать.
- Например, вводится эмодзи вроде `🗡️` или `⚔️`.
___

## Цвет
Настройка цвета показа элемента
- Как цвет элемента он применяется к значку элемента и к цвету фона.
- Выбирается в палитре цветов редактора.
- Чёрный (`#000000`) считается значением, которое означает «цвет не задан». Начальное значение палитры — тоже этот чёрный.
- Если нужен чёрный вид, укажите чуть смещённый цвет, например `#010101`.
___

### Наследование от родительского элемента
Перенятие настройки цвета родительского элемента
- Действия, предметы и события без заданного цвета перенимают цвет категории, которой принадлежат.
- Иерархия наследования такова.
- У элемента с отдельно заданным цветом этот цвет имеет приоритет. Он не перезаписывается, даже если у категории есть цвет.
- Основной способ — задать цвет для каждой категории, а всё, что ниже, оставить наследованию. Отдельный цвет задают, когда хотят выделить конкретный элемент.
- Если у действия задан атрибут (attribute), перенимается цвет не той категории, которой оно принадлежит, а той, что указана в атрибуте.
- У самой категории наследовать не от кого. Если цвет категории остаётся чёрным (`#000000`), эта категория и элементы под ней без заданного цвета показываются цветом посередине между цветом полосы и цветом текста из дизайна.
- Группы, навыки и пресеты не наследуют и используют только цвет, заданный им самим.
```
world (basic.design)
└── category
    ├── action
    ├── item
    └── event
```
- [_type_](ru/editor/type)

## Копирование сведений
Дублирование информации другого элемента
- Нажатие кнопки `Copy Information` разом копирует информацию другого элемента в этот элемент.
- Выберите тип источника копирования (категория, действие, предмет, группа, событие, навык или пресет) и следом введите его ID.
- Перезаписываются все поля, включая идентификатор. После копирования смените идентификатор на неповторяющийся.
- [_type_](ru/editor/type)
