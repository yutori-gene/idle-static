
# Событие
Все события мира, объединяющие задачи, события изменения и фиксированные события
- События мира состоят из трёх видов: задачи (tasks), события изменения (changed) и фиксированные события (unique).
- Задача — это миссия, которая считается выполненной при соблюдении условий.
- Событие изменения — это событие для внутренней обработки, не показываемое на экране: оно срабатывает раз за разом, когда его запускает прирост количества.
- Фиксированное событие — это ячейка, готовая по одной на каждый момент, которую нельзя ни добавить, ни удалить.

|Вид|Описание|
|-|-|
|[_task_](ru/editor/task)|Миссия, которая считается выполненной при соблюдении условий|
|[_changed_](ru/editor/changed)|Событие для внутренней обработки, которое срабатывает, когда количество категории, действия или предмета за один раз выросло не меньше, чем на величину в условиях|
|[_unique_](ru/editor/unique)|Сообщения и награды, срабатывающие в определённые моменты|
