
# Условие
Настройка условий, нужных для использования или показа элемента
- Это условия, которые задаются каждому элементу: категории, действию, предмету и событию.
- Пока не выполнены все заданные условия, действие, указанное в таблице, невозможно.
- В зависимости от настройки открытия (unlocked) элемента, сам элемент не показывается на экране, пока условия не выполнены.

|Где задаётся|Что невозможно, пока условия не выполнены|
|-|-|
|Категория|Выполнение всех действий категории и операции с её предметами|
|Действие|Выполнение действия|
|Предмет|Операции с предметом (снаряжение и прочее)|
|Событие|Выполнение задачи, запуск события изменения и фиксированного события|
- [_type_](ru/editor/type)
___

## Тип
Вид элемента, к которому обращается условие

|Тип|Значение, к которому идёт обращение|
|-|-|
|Категория|Уровень категории|
|Действие|Число выполнений действия|
|Предмет|Количество предмета во владении|
___

## ID элемента
ID элемента, к которому обращается условие
- Задайте ID категории, действия или предмета, к которому обращается условие.
- Если у события включён подсчёт по группе (requiringGroup), это считается ID группы, а не отдельного элемента.
___

## Значение
Число, нужное для условия
- Условие выполняется, когда значение не меньше указанного.
- Задаётся целым числом от 0 и выше. Значение по умолчанию — `1`.
___

## Вероятность расхода [0-1]
Вероятность того, что предмет будет израсходован (от 0 до 1, работает только если тип — предмет)
- Это вероятность израсходовать предмет, когда условия выполнены и действие выполняется.
- При `1` он расходуется всегда, при `0.5` — с вероятностью 50%, при `0` не расходуется.
- Значение по умолчанию — `1` (расходуется всегда). Но в условиях события (задачи, события изменения, фиксированного события) значение по умолчанию — `0` (не расходуется), чтобы при выполнении запас не уменьшался.
- При `0` запас не уменьшается, поэтому действие можно выполнять сколько угодно раз, пока количество во владении достигает значения условия. Используйте это, когда условием должно быть только наличие снаряжённого предмета.
- Если тип не предмет, настройка не работает.
___

## Снаряжение
Требовать ли по условию, чтобы предмет был снаряжён (работает только если тип — предмет)
- Если включить, условие потребует не только владеть предметом, но и держать его снаряжённым.
- Снаряжён предмет или нет, определяется по снаряжению той категории, которой он принадлежит.
- Если тип не предмет, настройка не работает.
