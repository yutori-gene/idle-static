
# Тип
Базовое деление мира
- Мир состоит из шести типов.
- Все элементы располагаются непосредственно под миром.
- Действия и предметы связываются по ID категории, которой они принадлежат.
- Только события не являются типом: они располагаются по моментам вместе в событиях (events) непосредственно под миром.

|Тип|Описание|
|-|-|
|[_category_](ru/editor/category)|Крупная рамка, которая распределяет действия и предметы|
|[_action_](ru/editor/action)|Элементы поведения — добыча, изготовление, бой и тому подобное|
|[_item_](ru/editor/item)|Элементы вещей: снаряжения, расходуемого и тому подобного|
|[_skill_](ru/editor/skill)|Особый эффект, который разыгрывается каждый ход боя и срабатывает|
|[_group_](ru/editor/group)|Определяет группы отображения категорий, действий, предметов и задач|
|[_preset_](ru/editor/preset)|Настройка отображения системных элементов|
```
world
├── category
├── action
├── item
├── skill
├── group
└── preset
```
