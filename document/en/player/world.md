
# World
Checking and setting the game as a whole
- It opens from the world heading in the top column.
- The column of the debug appears only when it is started in debug mode.
___

## Overview
Showing the overview of this world and of the console running it
- You can check the identity of the world, such as its author, version, and estimated play time, along with the settings shared by the whole world, such as the default language, the maximum offline hours, the category level cap, and how steeply the required experience grows
- The console is the runtime that loads and runs a world. It has its own version and update date, separate from the world
___

## Statistics
Showing the totals recorded through play
- You can check the totals for play time and coins earned, and how many item slots and queue slots you can hold right now
- The unlocked counts for categories, actions, items, and events use the world's total as the denominator, including those you have not found yet
- Tapping coins, capacity, the queue, or a category in the breakdown opens that screen
___

## Settings
Changing the settings of this game and managing the save data
- You can change the controls, the display, and the processing load. Settings are saved as part of the progress data and carried over into exported data
- Progress data is saved on this device for each world. An exported file can only be loaded by the same version of the same world
___

## Debug
Providing the tools for testing a world
- Shown only when launched in debug mode. It does not appear in normal play
- The acceleration setting is saved in the progress data, but it only takes effect while in debug mode
