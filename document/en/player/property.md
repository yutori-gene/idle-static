
# Property
The numbers that affect the result of an action
- A property is a numeric adjustment that affects the result of executing an action
- Opening it from a category shows the list of contributing items, from an item the list of affected categories, and from a skill only the adjustment values
___

## Property List
The list of the properties that belong to this category
- A property is an element that affects the execution of actions
- The tags listed below are the items contributing to that value, with their breakdown
- An item from another category also takes effect if this category is its target
___

## Calculation
The values of the properties applied to an action and their breakdown
- The applied value is not added or subtracted; a multiplier is applied for every 10 levels of difference. Attack and experience increase, while defence and the required time decrease
- How strongly it works differs from property to property
- Accuracy, evasion, success rate, and recovery never go below 0% or above 100%
